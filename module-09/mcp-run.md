# MCP Run — Scoped GitHub Action

## Brief

**Task:** Open one GitHub issue reporting the notes-api-smoke result.
**Server:** GitHub MCP server (`github.com/modelcontextprotocol/servers/tree/main/src/github`).
**Scope:** Single repo — `BeDigital/Claude-Code-Bootcamp` only. No other repos, no PRs, no merges.
**Allowed action:** `create_issue` — one call, one issue.
**Stop condition:** Issue URL returned by `create_issue`. Agent stops immediately after.
